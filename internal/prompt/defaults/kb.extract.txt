The input is a set of public conversations from a team chat. Each block is one thread, introduced by its channel and thread IDs, and every message in it is preceded by its source_id. Find knowledge in these threads that is worth keeping for later questions from anyone on the team, such as how a process works, what was decided, background on a project or team, or a useful conclusion the discussion reached. Judge every thread separately; it may yield nothing, one item, or several.
Leave out anything private or sensitive, anything about one person's own life or preferences, rumours and guesses, and claims about the wider world that the thread does not back up. Chit-chat, thanks, and error output carry no knowledge.
Every item needs the source_ids of the messages it rests on, a topic and tags drawn from the text, a memory_type, a confidence from 0 to 1, and a single sentence of rationale on why it will stay useful. Return only the items to keep.
Return a JSON array like [{"summary": "...", "source_ids": ["..."], "topic": "...", "tags": ["..."], "memory_type": "...", "confidence": 0.8, "rationale": "...", "store": true}], where memory_type is one of assistant_insight, brand_strategy, decision, external_fact, process, project_context, team_context. Return NULL when there is nothing to keep.
